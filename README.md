# 🧠 Hassan AI OS

**نظام تشغيل ذكاء اصطناعي خاص بحسن:** عدة نماذج تفكّر، الأدلة تحكم، وجهازك ينفّذ.
Model-agnostic multi-agent control plane — many models think, evidence decides, your machine executes.

```text
أنت ─► Hassan Manager ─► Analyst ─► Planner ─► ( Researcher ∥ Coder×N ) ─► Reviewer + Cross-Reviewer
                                                                               │
          Decision ◄── Verify (Build/Tests) ◄── Apply ◄── موافقتك ◄── Diff ◄── Judge (بالأدلة)
                              │
                     فشل؟ ─► Coder يصلح ─► Diff جديد ─► موافقتك ─► Verify   (حتى HASSAN_MAX_REPAIR_ROUNDS)
```

## التشغيل على Windows

```text
start.bat          :: الأساسي
start-full.bat     :: مع دعم MCP
```

ثم افتح `http://127.0.0.1:8787`.

يبدأ بوضع `mock` — كل الدورة تعمل **بدون مفاتيح API وبدون تكلفة**، والتنفيذ الحقيقي (Checkpoint/Build/Tests/كتابة الملفات) حقيقي تماماً.
في وضع mock، لتجربة دورة التعديل اكتب في المهمة: `[[write path/file.py]]المحتوى[[/write]]`.

المجلدات المسموح للوكلاء العمل فيها تُحدد بـ `HASSAN_ALLOWED_ROOTS` (الافتراضي: مجلد المستخدم).

Linux/macOS: `./start.sh`

## التثبيت الدائم على Windows (يشتغل لحاله مع الويندوز)

بعد `git pull`، اضغط دبل كليك على **`install.bat`**. رح:
- يثبّت النظام ويشغّله **بالخلفية بدون نافذة سودا**
- يخليه **يشتغل لحاله كل ما يفتح الويندوز**
- يعمل أيقونة **Hassan AI** على سطح المكتب بتفتح الواجهة
- يضيف أمر **`hassan`** لأي Terminal (ومنها Terminal تبع VS Code)

الإعدادات في `hassan.env` (الوضع، المجلدات المسموحة). للتحديث: دبل كليك على **`update.bat`**. للإزالة: `scripts\uninstall-windows.ps1`.

| أمر | شو بعمل |
|---|---|
| `hassan open` | يشغّل النظام إذا مش شغّال ويفتح الواجهة |
| `hassan ask "افحص المشروع"` | يبعت مهمة، والمشروع = المجلد اللي أنت فيه |
| `hassan ask "..." --execute` | مع Checkpoint + Build + Tests |
| `hassan status` / `hassan stop` / `hassan start` | الحالة / إيقاف / تشغيل |

## 🖥️ تحكم بالكمبيوتر (Operator)

بالواجهة اختار **🖥️ تحكم بالكمبيوتر** واكتب/احكي المهمة، مثلاً: *"رتّب ملفات التنزيلات بمجلدات حسب النوع"*.
المشغّل بيشتغل خطوة خطوة (بأي عقل متاح: ChatGPT/Gemini/Claude/مجاني):

| تلقائي | بيستنى موافقتك (من الكمبيوتر أو التلفون) |
|---|---|
| يشوف مجلد، يقرأ ملف، يدوّر، معلومات الجهاز، يعمل مجلد، يفتح مجلد/مستند/موقع | يكتب ملف (بتشوف الفرق)، ينقل، ينسخ، يحذف، **يشغّل أمر** (بتشوف الأمر بالحرف)، يشغّل برنامج |

- الحذف **بيروح لسلة Hassan** (`data/trash`) مع مكانه الأصلي — بترجّعه وقت ما بدك. والكتابة فوق ملف بتحفظ نسخته القديمة هناك.
- بيشتغل بس جوّا `HASSAN_ALLOWED_ROOTS` (افتراضياً مجلد المستخدم). ما بيلمس كلمات السر، مفاتيح SSH، بيانات المتصفح، ولا ملفات Hassan الخاصة.
- إذا رفضت خطوة، ما بيعيدها وبيدوّر على طريقة ثانية. زر **⏹ أوقف** يطلب إلغاء المهمة؛ تُعرض «جارٍ الإيقاف» حتى يكتمل تنظيف العمل الجاري. التغييرات التي تمت لا تُلغى تلقائيًا.
- شريط أصفر فوق أي صفحة (وإشعار) لما في طلب موافقة بستناك.
- العقل المستخدم: `operator` في `configs/providers.yaml`.

## الماوس والكيبورد من المتصفّح (تحكّم يدوي)

1. شغّل Hassan على **Windows**. عرض الشاشة يحتاج FFmpeg؛ يوفّره `scripts\enable-apps.bat`.
2. من صفحة الكمبيوتر `http://127.0.0.1:8787` اختر **السماح بالتحكّم لمدة 30 دقيقة** أو **السماح الدائم لأجهزتي**. الدائم يبقى بعد إعادة تشغيل التطبيق؛ لا يبدأ جلسة إدخال تلقائيًا.
3. من هاتفك افتح رابط HTTPS الخاص بـTailscale وسجّل الدخول برمز الربط، ثم اضغط **افتح الشاشة وتحكّم**. يبقى الكمبيوتر والتطبيق شغّالين طوال الاستخدام.
4. على الهاتف يمتلئ عرض المتصفح بالشاشة؛ لفّ الهاتف أفقيًا لمساحة أكبر. **كبسة قصيرة** للنقر، و**سحب بإصبع أو إصبعين** للتمرير. للتظليل أو سحب عنصر، **ثبّت إصبعك نحو نصف ثانية ثم اسحب**. الإطار الأصفر يشير إلى وضع التظليل.
5. زر **⌨️ كتابة** يفتح حقل كيبورد الهاتف. حدّد الخانة على الكمبيوتر ثم اكتب النص وأرسله. من «أدوات» كبّر الصورة ×2 وحرّك العرض؛ «العودة للنقر» يعيد إيماءات التحكّم.
6. الاختصارات تشمل ابدأ، مستكشف الملفات، تبديل البرامج، التحديد والقص والتراجع. Ctrl+C وCtrl+V هنا يعملان على **حافظة الكمبيوتر**؛ نقل النص بين الجهازين له كرت مستقل أدناه.

**وقف التحكّم** ينهي الإدخال ويُبقي العرض والسماح الدائم. إيقاف عرض الكمبيوتر ينهي جلسة الإدخال أيضًا. **إلغاء السماح** أو زر **إيقاف التحكّم فورًا** أو تغيير مفتاح الدخول يلغي السماح المحفوظ. لا يتجاوز التحكّم شاشة دخول Windows أو UAC أو صلاحيات التطبيقات المرتفعة.

يتحكّم جهاز واحد بالماوس والكيبورد في كل مرة. إذا كان الإيجنت يعمل على الكمبيوتر، طلب التحكّم اليدوي يوقف مهمته وينتظر انتهاء تنظيفها قبل تسليم الإدخال؛ إذا لم تنتهِ المهلة لا يُفرض الاستيلاء. لا يستطيع جهاز يدوي ثانٍ الاستيلاء على جلسة المستخدم. انقطاع الاتصال أو فقدان التركيز أو انتهاء السماح يحرّر الأزرار، وكذلك خمول الإدخال. **Esc** يحرّر التركيز؛ زر Esc في الأدوات يرسله إلى الكمبيوتر.

### جودة الشاشة واختيار الشاشة

افتح **جودة العرض والشاشة** قبل تشغيل العرض:

| الاختيار | أقصى أبعاد الصورة | المعدل المطلوب |
|---|---|---|
| توفير البيانات | 960 × 540 | 6 إطارات/ثانية |
| متوازن | 1280 × 720 | 12 إطارًا/ثانية |
| أوضح وأنعم | 1920 × 1080 | 15 إطارًا/ثانية |

تُحفظ نسبة أبعاد الشاشة ولا تُكبّر الصورة فوق حجمها الأصلي. «تلقائي» يختار توفير البيانات عندما يعلن المتصفح اتصالًا بطيئًا أو وضع توفير البيانات؛ وإلا يختار المتوازن. الاختيار يتم **عند فتح العرض فقط**، وليس ضبطًا مستمرًا أثناء البث. تغيير الجودة أو الشاشة يُطبّق بعد إيقاف العرض وفتحه مجددًا.

يمكن عرض كل الشاشات أو شاشة Windows محددة، وتُحوّل النقرات إلى مكانها على سطح المكتب. عند تغير ترتيب الشاشات قد يلزم فتح العرض مجددًا. البث الحالي **MJPEG عبر FFmpeg**؛ السرعة الفعلية تعتمد على الجهاز والاتصال، والجودة الأعلى تستهلك بيانات أكثر. لا يوجد WebRTC في هذا الإصدار.

## 💡 مجاني أولاً — والمدفوع بموافقتك بس

- **الافتراضي: كل شي على العقول المجانية** (Groq / Gemini API / OpenRouter).
- العقول **المدفوعة** (اشتراكات Claude / ChatGPT / Gemini — `paid` بـ`providers.yaml`) **ما بتنستخدم إلا بموافقتك**:
  لما المهمة صعبة (برمجة/تخطيط/تحليل) أو المجاني فشل، بيطلعلك طلب **💳 "بدي أستخدم عقل مدفوع — ليش — توافق؟"**
  (بالواجهة، التلفون، أو زرّين بتيليجرام). بيسأل **مرة وحدة لكل مهمة**؛ إذا رفضت بيكمل بالمجاني قد ما بيقدر.
- اختيار **العقل (التكلفة)** بالواجهة: 🆓 مجاني ويسألني (الافتراضي) · 🆓 مجاني بس ولا تسألني · 💳 مسموح المدفوع حسب الصعوبة · 💳 أقوى عقل.
- تيليجرام: بدون أمر = مجاني ويسأل · `/free` مجاني بس · `/best` أقوى عقل مدفوع.
- مستوى المهمة (🆓 سهلة / ⚖️ متوسطة / 🧠 صعبة) بينفرز مجاناً وبيظهر جنب المهمة؛ `tiers` بتحدد ترتيب العقول لكل مستوى.

## ✈️ تيليجرام + مهام مجدولة + ذاكرة ومهارات (أفكار من Hermes Agent)

**تيليجرام** (من الواجهة على الكمبيوتر، كرت ✈️):
1. بتيليجرام افتح **@BotFather** ← `/newbot` ← انسخ الـtoken ← الصقه بالكرت ← حفظ.
2. اضغط **أعطيني رمز ربط** وابعت للبوت `/pair 123456`.

بعدها من تيليجرام: اكتب أو **ابعت رسالة صوتية** (بتنفهم عن طريق Whisper المجاني من Groq — بدها مفتاح Groq)،
والموافقات بتوصلك **أزرار** (✅ / ❌ / ✅✅ المشابه)، والنتيجة والصور والرندر بتوصلك بالمحادثة.
أوامر: `/team` `/status` `/stop` `/remember` `/schedule` `/schedules` `/unschedule` `/help`.
- بس المحادثات المربوطة برمز بتنسمع؛ غيرها بينرفض. التوكن محفوظ بـ`hassan.env` على الكمبيوتر بس.
- ما بيفتح أي بورت على الكمبيوتر (long polling).

**مهام مجدولة**: `daily 08:00 …` · `weekly sun 09:00 …` · `every 2h …` (من الواجهة أو `/schedule`). النتيجة بتوصلك على تيليجرام.

**ذاكرة**: "شو بعرف عنك" — معلومات بتحكيله إياها (أو `/remember`) بتدخل بكل مهمة. ما بيحفظ كلمات سر.
**مهارات**: بعد مهمة ناجحة متكررة، المشغّل بيحفظ الطريقة كمهارة (`data/skills`) وبيرجعلها المرة الجاية، وبيحسّنها.
**بحث بالتاريخ**: بيقدر يدوّر بالمهام القديمة ونتائجها.

| **Blender** | سكربتات bpy بالخلفية: يبني، يعدّل، يصدّر، **يرندر** (الصورة بتطلعلك بالواجهة) | ✓ |
| **VS Code** | أداة `vscode`: يفتح مجلدات/ملفات (وعلى سطر معيّن) | تلقائي |
| **الإنترنت** | بحث + قراءة صفحات، أو يفتح الموقع بمتصفحك | تلقائي (العناوين الداخلية ممنوعة) |
| **الشاشة** | لقطة شاشة بتشوفها من التلفون | تلقائي |
| **الكاميرا / المايك** | صورة / تسجيل صوت، بيطلعوا بالواجهة | ✓ دائماً |
| **فيديو وصوت** | ffmpeg: قص، دمج، تغيير حجم، ترجمة… | ✓ |

- زر **"✓✓ وافق على كل الخطوات المشابهة بهاي المهمة"** بيوفّر عليك (مثلاً كل النقرات بـCapCut). **الحذف، الأوامر، الكاميرا والمايك بيسألوا كل مرة.**
- أدوات Windows-MCP الخطيرة (PowerShell، Registry، FileSystem) **مطفية** بالخادم نفسه وممنوعة بالسياسة كمان — أدوات Hassan المحمية بتعمل هالشغل.
- CapCut ما إله API رسمي؛ التحكم بيصير بالنقر زي الإنسان (أبطأ). للمونتاج الثقيل ffmpeg أسرع وأضمن.

## 📱 التحكم من التلفون (من أي مكان)

1. على الكمبيوتر: دبل كليك على **`scripts\enable-phone.bat`**، بيثبّت **Tailscale** (مجاني) وبيسجّلك، وبيعمل رابط HTTPS خاص.
2. على التلفون: ثبّت تطبيق **Tailscale** وسجّل **بنفس الحساب**.
3. بالواجهة على الكمبيوتر، كرت **📱 التلفون**: امسح رمز الـQR بكاميرا التلفون.
4. من قائمة المتصفح: **Add to Home screen** → بيصير تطبيق على التلفون.

من التلفون: تبعت مهام بالكتابة أو بالصوت 🎤، توافق/ترفض التعديلات، تشوف الاستهلاك، وتفتح ملفات بـVS Code على الكمبيوتر.

إدارة الوصول:

- الاتصال عبر شبكة Tailscale الخاصة؛ لا تحتاج فتح منفذ عام على الراوتر.
- الـQR ورمز الأرقام مؤقتان ويُستخدمان مرة واحدة. بعد الربط يحصل كل متصفح على جلسة دخول مستقلة؛ الـQR لا يحتوي مفتاح الكمبيوتر الدائم.
- من كرت **الأجهزة المرتبطة** تستطيع تسمية الجهاز أو إلغاء جلسته من الكمبيوتر. الإلغاء يمنع طلباته الجديدة ومدخلاته التالية، مع بقاء الأجهزة الأخرى.
- المتصفحات القديمة التي تحمل مفتاحًا مشتركًا تُرقّى تلقائيًا عند الزيارة. **من يعرف المفتاح القديم يستطيع الربط مجددًا ما دام المفتاح صالحًا**؛ إلغاء جلسة متصفح لا يبطل نسخة ذلك المفتاح. زر **تغيير المفتاح** يبطل المفتاح السابق ويفصل الجلسات والهواتف المربوطة ويلغي السماح بالتحكّم؛ أعد ربط أجهزتك بعده.
- لإيقاف رابط Tailscale على الكمبيوتر: `tailscale serve reset`.

بديل داخل شبكة Wi-Fi فقط: `HASSAN_HOST=0.0.0.0` في `hassan.env`. التحكّم اليدوي البعيد يحتاج HTTPS؛ الرابط غير المشفر لا يكفي له، كما أن الميكروفون يحتاج سياقًا آمنًا في المتصفح.

## 📱 الكمبيوتر والإيجنت يتحكّموا بهاتف Android

هذا هو الاتجاه العكسي: تطبيق صغير على الهاتف يتصل بخادم Hassan عبر الإنترنت وTailscale. **العقل وتنفيذ خطة الإيجنت يبقيان على الكمبيوتر**؛ التطبيق يتيح وصف عناصر الهاتف والتحكّم المصرّح به. لا يحتاج ADB أو root أو منفذًا واردًا إلى الهاتف.

1. شغّل Tailscale على الجهازين وسجّلهما في شبكتك. افتح رابط Hassan مثل `https://my-pc.example.ts.net` من الهاتف وتأكد من الوصول.
2. من كرت **تلفونك من الكمبيوتر → ربط تلفون جديد** نزّل التطبيق. رابط تنزيل APK في الخادم هو `/api/phones/app`، ويتطلب تسجيل الدخول وتوفّر بناء التطبيق على الخادم. ثبّته على Android 8 أو أحدث.
3. من صفحة الكمبيوتر أنشئ رمز ربط، ثم أدخل في التطبيق الرابط الأساسي HTTPS والرمز واسم هاتفك. لا تضع مفتاح الكمبيوتر العام داخل التطبيق.
4. من الهاتف فعّل خدمة **Hassan** ضمن إعدادات **تسهيل الاستخدام / إمكانية الوصول**، ثم فعّل زر السماح بالتحكّم في التطبيق. يمكن حفظ هذا السماح حتى تطفئه؛ Android أو توفير الطاقة قد يوقف الخدمة.
5. لمشاهدة الصورة اضغط **ابدأ عرض الشاشة** في التطبيق ووافق على نافذة Android، ثم **اعرض شاشة التلفون** في صفحة الكمبيوتر. للتحكّم اضغط **ابدأ التحكّم**: نقرة للنقر، وسحب للتمرير، وأزرار الرئيسية والرجوع والتطبيقات، وحقل للنص العربي.
6. أو اكتب تحت **خلي الإيجنت يشتغل على التلفون**. يبدأ بمراجعة الهاتف ويعرض الموافقات والخطوات ضمن المهمة. تتوقف جلستك اليدوية قبل تسليم الهاتف للإيجنت.

**عرض الصورة والسماح بالتحكّم مستقلان.** «إخفاء العرض هنا» يخفي الصورة في هذا المتصفح فقط. «إيقاف مشاركة شاشة الهاتف» ينهي البث من الهاتف؛ وفي التطبيق يوجد «أوقف عرض الشاشة فقط» و«إيقاف العرض وكل التحكّم». يستطيع الإيجنت قراءة عناصر الواجهة المسموح بها والعمل حتى مع توقف الصورة، ما دام السماح وخدمة إمكانية الوصول فعالين والهاتف مفتوح القفل.

Android يطلب **موافقة جديدة لكل جلسة عرض شاشة**؛ السماح الدائم لا يحفظ موافقة النظام للبث ولا يفتح قفل الهاتف. بعض التطبيقات تمنع العرض أو لا تتيح عناصر يمكن التحكّم بها. حقل الكتابة يستبدل نص الحقل المحدد، ولا يكتب في حقول كلمات السر. بث الهاتف صور JPEG بحد أقصى صورتين في الثانية، وليس بث فيديو سلسًا.

**اختبار الهاتف الفعلي ما زال مطلوبًا**: نجاح بناء APK والاختبارات الآلية لا يثبت اللمس أو العربية أو القفل والدوران على جهازك. تفاصيل الربط والبناء والحدود في [دليل تطبيق Android](android-companion/README.md).

## 📂 نقل الملفات والنسخ بين الأجهزة

في كرت **ملفات ونسخ بين أجهزتك**، اختر ملفًا من الجهاز الذي تستخدمه واضغط **ارفع الملف**. افتح الصفحة من جهازك الثاني واضغط اسم الملف لتنزيله. يعمل الاتجاهان بهذه الطريقة؛ لا يبحث النظام في ملفات الهاتف أو الكمبيوتر ولا يفتح الملف أو ينفذه تلقائيًا.

الحد **25 MiB للملف**، و**250 MiB إجمالًا**، وحتى **200 ملف**؛ تُعرض MiB تقريبًا كميغابايت في الواجهة. يظهر SHA-256 لكل ملف وتُفحص بصمته قبل التنزيل. لا يوجد حذف ملفات من هذا الكرت في الإصدار الحالي.

في **نسخ نص بين الجهازين**، ابدأ جلستك اليدوية على الكمبيوتر أولًا. زر **اقرأ حافظة الكمبيوتر** يضع النص في الخانة الظاهرة؛ حدّده واستخدم «نسخ» من جهازك. بالاتجاه الآخر الصق نصك في الخانة واضغط **ضع النص في حافظة الكمبيوتر**، ثم الصقه بنفسك في البرنامج. لا توجد قراءة دورية للحافظة، ولا طلب تلقائي لصلاحية حافظة المتصفح، ولا لصق تلقائي داخل البرامج. الحد 65,536 حرفًا؛ الأجهزة البعيدة تحتاج نفس جلسة الدخول التي تملك التحكّم اليدوي الحالي.

## الاستهلاك

## تشغيل Claude و ChatGPT الموجودين عندك (باشتراكك، بدون API)

النظام يشغّل **Claude Code** و **Codex (ChatGPT)** على جهازك كـ"عقول" للوكلاء، باستخدام تسجيل الدخول باشتراكك.

```text
npm i -g @anthropic-ai/claude-code   ثم  claude        (سجّل دخول بحساب Claude Pro/Max مرة واحدة)
npm i -g @openai/codex               ثم  codex login   (Sign in with ChatGPT)
start-live.bat
```

توزيع الوكلاء في `configs/providers.yaml` (افتراضياً: Claude يبرمج ويحكم، ChatGPT يخطط ويراجع، وكل واحد احتياط للثاني).

- العقول تعمل في مجلد مؤقت فارغ، بدون أدوات (Claude: `--tools ""`، Codex: `--sandbox read-only`) — **تفكر وتجاوب فقط**؛ أي تعديل على مشروعك يمر عبر Diff وموافقتك.
- `use_subscription: true` يخفي `ANTHROPIC_API_KEY`/`OPENAI_API_KEY` عن الـCLI حتى يُحسب الاستخدام على اشتراكك وليس على API.
- الاشتراك له حدود استخدام؛ وضع Consensus يستهلك أسرع. إذا وصل Claude للحد، النظام ينتقل تلقائياً لـChatGPT والعكس.
- حالة العقول ظاهرة في الواجهة وفي `/api/providers`.

## Gemini (باشتراك Google)

```text
npm i -g @google/gemini-cli     ثم  gemini   (سجّل دخول بحساب Google مرة واحدة، ثم /quit)
```
Gemini بيشتغل كعقل ثالث (الباحث + المبرمج الثالث بوضع Consensus + احتياط)، بوضع قراءة فقط (`--approval-mode plan`).

## احتياط مجاني: ما بيوقف لو خلص الاشتراك

الترتيب لما عقل يوقف (حد الاشتراك، مش مثبت، …): **ChatGPT → Claude → Gemini → Groq → Gemini API → OpenRouter** (`fallback` في `configs/providers.yaml`).

من الواجهة على الكمبيوتر، كرت **🔑 APIs مجانية**: الصق مفتاح مجاني واضغط **حفظ** (بيجرّبه فوراً):

| الخدمة | مجاناً | المفتاح |
|---|---|---|
| **Groq** (الأسرع) | ~1,000 طلب/يوم (gpt-oss-120b) | console.groq.com/keys |
| **Gemini API** | طبقة مجانية (Google ممكن تستخدم بيانات الطبقة المجانية للتحسين) | aistudio.google.com/apikey |
| **OpenRouter** | `openrouter/free` بيختار نموذج مجاني متاح | openrouter.ai/keys |

- المفاتيح بتنحفظ بـ`hassan.env` على الكمبيوتر بس (مش على GitHub)، وما بتنعرض أبداً، والتلفون ما بيقدر يقرأها أو يغيّرها.
- لكل خدمة قائمة نماذج؛ إذا نموذج انشال، بيجرّب اللي بعده. إذا وصلت للحد (429) بتتخطّى مؤقتاً.

## تشغيل النماذج عبر API (Grok + DeepSeek + محلي …)

1. `copy configs\litellm.example.yaml configs\litellm.yaml` وعدّل أسماء النماذج (الموجودة placeholders).
2. ضع المفاتيح في متغيرات البيئة: `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `XAI_API_KEY`.
3. `scripts\start-litellm.ps1`
4. `set HASSAN_AI_MODE=live` ثم `start.bat`

الوكلاء يشيرون إلى **أسماء مستعارة** (`coder`, `judge`…) وليس إلى شركة. تبديل النموذج = تعديل سطر في `litellm.yaml`، بدون لمس الكود.
سلسلة الـfallback لكل وكيل في `configs/agents.yaml`.

## استكمال المهام والتحقق من النتائج

إيقاف المهمة ينتقل من «جارٍ الإيقاف» إلى «متوقفة» بعد تنظيف الأوامر والعمليات التابعة. الكتابة الجارية تنتظر اكتمالها قبل تأكيد الإيقاف. هذا لا يتراجع عن تعديل سبق تنفيذه، ولا يضمن إيقاف عمل مستقل داخل تطبيق أو خدمة خارجية.

تُحفظ الخطوة المقصودة ونتيجتها في المهمة. بعد انقطاع أو إعادة تشغيل، استخدم **استكمال المهمة** لبدء متابعة مرتبطة بالمهمة الأصلية؛ لا تبدأ متابعة تلقائيًا. المتابعة تفحص الجهاز مجددًا وتطلب موافقات جديدة ولا تعيد التغييرات التي سُجّل تأكيدها. إذا انقطع الاتصال أثناء خطوة ولم تصل نتيجتها، تحتاج تحديد هل تمت فعلًا بعد فحص الجهاز؛ لا نفترض نجاحها أو نكررها عميانيًا.

التحقق من النتائج يشمل محتوى الملفات وبعض آثار النسخ والنقل وسلة الاسترجاع. بعد تغييرات واجهة الهاتف تُقرأ عناصر إمكانية الوصول مجددًا؛ وعلى Windows تُستخدم أداة وصف الشاشة المتاحة والمسموح بها. يمكن فحص ظهور نص مطلوب، ويمنع غياب الفحص النهائي أو فشل شرطه إعلان اكتمال المهمة.

**نجاح نقرة أو قراءة واجهة لا يثبت تحقق الهدف كاملًا.** لم تُضف هنا مقارنة صور ذكية تثبت جودة تصميم أو مونتاج أو رندر. بعض التطبيقات والرسومات المخصصة لا تعرض معلومات كافية للتحقق، وتبقى النتيجة غير محسومة. نفاد الخطوات أو أخطاء الأدوات لا تُعرض كمهمة مكتملة.

«جاهزية الإيجنت» يفحص الإعدادات دون تشغيل نموذج مدفوع. وجود مفتاح أو برنامج لا يثبت صحة تسجيل الدخول أو توفر الرصيد. تفاصيل الملكية والاستكمال والأدلة وحدودها في [دليل الاعتمادية](docs/reliability.md).

نتائج الاختبارات الحالية وبناء Android موجودة في [GitHub Actions](https://github.com/hasanawida/hasan-agent/actions). لا توجد مقارنة أداء مثبتة مع منتجات أخرى؛ اختبار المهام الواقعية على Windows والهاتف هو الخطوة اللازمة لقياس الاعتمادية والسرعة.

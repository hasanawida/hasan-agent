خمسة فيديوهات تدور بلا نهاية (60fps): البيان 14 ثانية ومتجر آيه 48 ثانية (مربّعان 1440×1440)، وثلاث ستوريات عمودية (1080×1920): Easy Steps حجز الفحص 37.3 ثانية، والمنتجات والتوصيل 42.7 ثانية، وستوري آيه السينمائي 48 ثانية.

## كيف يعمل

- **ملف HTML واحد** لكل فيديو (`albayan-loop.html`, `aya-loop.html`): الخطوط والصور مدمجة. كل style يُحسب من الزمن داخل `seek(t)`: لا CSS transitions، لا timers، لا حالة تنتقل بين الإطارات.
- **الزنبركات** استجابة خطوة مغلقة الصيغة (damping ≥ 0.8 → overshoot ≤ 1.5%). القيمة التي تتغيّر عدة مرات = مجموع زنبرك لكل تغيير (`Track`)، وكل حدث يُحسب أيضًا من الدورة السابقة (`t + T`) فتصبح الدالة دورية تمامًا: `seek(0) === seek(14)` بكسلًا بكسلًا، ومكان المؤشر وسرعته متطابقان عند نقطة الالتفاف (`render.mjs loopcheck`).
- **حافتا** مؤشر التبويبات ومقبض المفتاح على زنبركين مختلفين: الحافة الأمامية أسرع فتتمدّد قبل الخلفية.
- **السحب مباشر**: أثناء الإمساك القيمة = دالة لموضع المؤشر؛ عند الإفلات ترجع بزنبرك حرّ من الإزاحة والسرعة التي كانت عليها.
- **الكاميرا** تقرّب لكل حالة، ولا تسمح أبدًا للشكل الحيّ بالخروج من الإطار (softmin مع zoom-to-fit). لا `will-change` على أي شيء (النص يبقى حادًّا).
- **النص** الذي يتبدّل داخل الشكل له توقيت خروج (أسرع) ودخول (متأخر) مستقل فلا يتداخل.

## الصوت

`tools/analyze_song.py` (numpy): tempo بـ comb filter، phase من الـ kick (المتوسط الهندسي لـ onset الترددات المنخفضة و«النقرة» — لأن الباص على الـ offbeat والهاي-هات على الـ «and»)، الـ downbeat من بداية المازورة الأولى، اختيار نافذة 7 مازورات، ثم `atempo` إلى 120 BPM بالضبط والتحقق بـ cross-correlation لقالب الـ kick:

| | BPM الأصلي | النافذة | انحراف الـ kick عن الشبكة |
|---|---|---|---|
| البيان — Deep House | 123.99 | 23.214 ث | كل الـ 28 نبضة ضمن ±2 ms |
| آيه — Getting Older | 123.00 | 68.284 ث (8 مازورات، تُكرَّر ×3 بلا قطع) | هجوم الـ kick −1 ms |
| Easy Steps — It's Just You | 90.00 (بدون تمديد) | 21.333 ث (8 مازورات) | هجوم الـ kick −0.06 ms |

كل أصوات الواجهة مولّدة بالكود (`tools/sfx.py`) وكل صوت يوضع بحيث تقع **ذروته المقاسة** على الحدث (`audio/sfx_report.json`). النغمات مضبوطة على مقام الأغنية. الموسيقى تُدمج عند نقطة الالتفاف (equal-power 120 ms) فلا يُسمع قطع.

الأغاني من Mixkit — [Mixkit Stock Music Free License](https://mixkit.co/license/#musicFree): استخدام تجاري مجاني بدون ذكر المصدر. ملفات الـ MP3 الأصلية لا تُرفع للمستودع (تُحمَّل تلقائيًا).

## التشغيل

```bash
cd motion && npm install
pip install numpy scipy imageio-ffmpeg

P=albayan-loop        # أو aya-loop
python3 tools/analyze_song.py $P/audio        # شبكة الإيقاع + music_120.wav
node tools/build.mjs $P                        # ملف HTML واحد
node tools/render.mjs $P beats 0.9             # إطار لكل نبضة + contact sheet
node tools/render.mjs $P loopcheck             # seek(0) == seek(T)؟
node tools/render.mjs $P cues                  # إشارات الصوت من نفس الدوال
python3 $P/audio/make_audio.py                 # mix.wav
node tools/render.mjs $P video                 # 4 subframes/frame → tmix → 60fps
node tools/render.mjs $P mux                   # out/<name>.mp4

# نسخة 2160×2160 (ثلاثة أجزاء بالتوازي ثم دمج بدون إعادة ترميز)
for k in 1 2 3; do node tools/render.mjs $P video --scale=1.5 --part=$k/3 & done; wait
node tools/render.mjs $P mux --scale=1.5       # out/<name>_2160.mp4
```

للإرسال على واتساب بجودة كاملة: أرسل الملف **كمستند (Document)** وليس كفيديو، لأن واتساب يضغط أي فيديو عادي.

افتح `albayan-loop.html?t=6.2` في المتصفح لرؤية أي لحظة.
